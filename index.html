FLASKMCX

重新定义 Minecraft 启动

基于 Python & Flask 全栈手搓，支持微软正版验证、64个线程极限并发下载、全主题自定义。为极客而生的下一代轻量级启动器。

// 极速并发下载

采用 64 线程多并发架构，榨干你的每一兆带宽。极速拉取 Mojang 官方资源，告别漫长等待。

// 微软正版安全认证

深度集成微软 OAuth 2.0 设备码认证流。本地 Refresh Token 加密缓存，一次登录，长期免密畅玩。

// 动态主题引擎

全 CSS 变量驱动，支持暗黑极客风、赛博粉紫等多种主题无缝切换，你的启动器由你定义。

// 极客精神 UI

抛弃臃肿的界面，拥抱原汁原味的终端风。纯原生前端三剑客打造，极低内存占用，甚至能在"小霸王"上跑。
